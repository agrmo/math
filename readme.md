# math

Math stuff.

## left-riemann

A left Riemann sum. e.g. `int_0^1 x^2` in 100 steps returns

```
0.32835
```

## right-riemann

A right Riemann sum. e.g. `int_0^1 x^2` in 100 steps returns

```
0.33835
```

## middle-riemann

A middle Riemann sum. e.g. `int_0^1 x^2` in 100 steps returns

```
0.323424
```
